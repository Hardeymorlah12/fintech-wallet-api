# fintech-wallet-api
Production-style fintech wallet REST API built with Java, Spring Boot, MySQL, JWT authentication, Docker, and CI/CD.

## Features
- User registration and login
- JWT authentication
- Wallet management
- Deposit and withdrawal
- Money transfer between users
- Transaction history
- Role-based authorization
- Global exception handling
- Docker support
- CI/CD pipeline

- ## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- MySQL
- JPA/Hibernate
- Maven
- Docker
- GitHub Actions

## Setup
1. Clone repository
2. Configure MySQL
3. Update application.properties
4. Run Maven install
5. Start application
